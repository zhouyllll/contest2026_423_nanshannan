# 相机预览帧率实测（2026-09-20）

镜像：ecc7cba 正常镜像。经 telnet 触发 `echo 1 > /tmp/k7-open-camera` 打开预览页，
独占串口抓 30 秒（`serial-preview-fps.raw`）。界面每 3 秒打印一次统计行。

| 项 | 实测 |
|---|---|
| 取帧 | 3 秒 91 次，平均 33 ms/次 → 约 30.3 fps |
| 显示新帧 | 3 秒 88 次 → 约 29.3 fps |
| 界面主循环 | 平均 2 ms |
| 汇总行 | `相机页 采集 311 帧 显示 301 帧 / 10 秒`、`采集 621 帧 显示 601 帧 / 21 秒` |

取帧的 33 ms 与传感器一帧的时间一致，即**瓶颈在传感器当前的工作模式，不在 CPU 或显示**：
IMX415 当前 1944x1097、VMAX=3165，一帧里有效行只占约三分之一，其余为空转
（行周期 782/74.25MHz = 10.53us，3165 x 10.53us = 33.3ms 正好 30fps）。
按 SDK 下限 VMAX = 有效行 + 46 = 1143 可到约 83 fps，且 MIPI 带宽不变（减的是空行）。
代价：最长曝光同比缩短到 36%，要补约 9dB 增益，噪点上升；另界面预览定时器为 30ms
（上限 33fps），要显示更高帧率需同步调小。板上可用 `cam vmax <行数>` 运行时调整，无需重编。
