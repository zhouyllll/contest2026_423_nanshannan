## 亚秒精度怎么来的

`date -u +%s` 只有整秒。每次取样连续轮询，捕捉板子秒数**跳变**的瞬间——那一刻板子正好
走到整秒边界，用此刻的主机时间对齐，偏差 = 板子整秒值 − 主机时刻，精度取决于跳变窗口
（`edge_window_s`，实测约 0.25s）。没抓到跳变时退化为整秒比较，记 `mode: coarse`。
